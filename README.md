\# Java Phase 1



My first Java projects while learning software engineering.



\## Topics covered

\- Variables, input (Scanner), operators

\- Conditions and loops

\- Methods

\- Arrays and ArrayList



\## Main project: Student Grade Manager

Reads student names and scores, then prints each student's letter grade,

the class average, the highest score, and the top student.



\## How to run

Open the project in Eclipse and run `phase1miniProject.java`.
